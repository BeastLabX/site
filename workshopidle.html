Game preview

Early visual direction for WorkshopIdle

The game is still in development, so this page uses the current concept image instead of final screenshots.

A workshop idle game with a clear first version

The current direction is a 2D side-view workshop where players repair machines, collect cash, upgrade their setup, and unlock better workshop visuals as they progress. The goal is to keep the first version clean, understandable, and fun without overloading it with too many systems.

Built for a reason

A smaller game idea with real workshop character

WorkshopIdle is being developed as a simple, focused idle game inspired by workshop repairs, machine jobs, tools, upgrades, and garage growth. It is planned as a casual game that fits inside the wider BeastLabX ecosystem while keeping its own workshop identity.
