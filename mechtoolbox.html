Core features

Built around real mechanic workflow

MechToolbox combines guided diagnostics, workshop tools, manuals, rebuild guidance, and drawing features in one dark industrial layout built around real workshop use.

Guided diagnostics

Start with the real symptom and work through practical diagnostic information instead of searching through disconnected notes.

  • Engine, hydraulic, electrical, and drivetrain systems
  • Symptom → check first → quick test → expected result
  • Likely cause and next-action guidance
  • Search across diagnostic categories

Drawing & fabrication

Create simple workshop designs without the complexity of full CAD. Build around the materials and connections you would actually use in the workshop.

  • Front, side, and top drawing workflow
  • Tube, pipe, rod, flat bar, angle iron, and common profiles
  • 3D project preview with rotate and zoom
  • Automatic lengths and angle calculations
  • Welded and bolted connection markers
  • Material estimation with PDF and STL export

Workshop tools

Fast-access calculations and technical references for everyday mechanical work.

  • Converters and torque calculations
  • Torque-angle tools and torque charts
  • Tap and thread reference
  • Gear-ratio calculations
  • Hydraulic, electrical, engine, and drivetrain references

Reference & Rebuild Assistant

Keep useful workshop information together and use guided rebuild structure when working on major components.

  • Saved PDF manuals
  • Workshop tips and practical guides
  • Rigging and hydraulic-symbol references
  • Workshop safety resources
  • Engine, transmission, and hydraulic Rebuild Assistant
